KP Cyber -> LL Exam Bot Chrome Auto-Fill Extension
===================================================

How to Install in Google Chrome (Takes 30 seconds):
1. Open Google Chrome and go to: chrome://extensions
2. Turn ON "Developer mode" (top-right toggle).
3. Click "Load unpacked" (top-left button).
4. Select this folder: E:\KP\chrome-extension

How to Use:
1. Log in normally to https://kabirservices.online/exam-bot in one Chrome tab.
2. Log in to your KP Cyber Admin Console (kpcyber.in/admin or portal-2a3.pages.dev/admin) in another tab.
3. Click "🚀 Exam Bot" on any candidate application (or click the extension icon in Chrome's toolbar).
4. The extension will automatically fill Application Number, DOB (converted to DD-MM-YYYY), Password, and attach the candidate's Photo so you can crop & submit!
